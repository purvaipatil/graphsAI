# graphsAI 📈

**graphsAI** is an AI-powered web application built with **Next.js**, **React**, and **Desmos API** that allows users to generate mathematical graphs using natural language input. It integrates the **Gemini-2.0-Flash** model to understand user queries and convert them into precise graph equations.

### 🌐 Live Demo
Check out the live version here: [graphsAI Website](https://graphs-ai.vercel.app/)

---

## ✨ Features

- 🧠 Uses **Gemini-2.0-Flash** to interpret natural language descriptions
- 📊 Renders interactive graphs using the **Desmos API**
- ⚡ Built with **Next.js** and **React** for fast, responsive performance
- 🔍 Supports a wide range of mathematical expressions and graph types
- 🧩 Easy-to-use interface for both students and educators

- **Deployment:** Vercel
